# PerfPilot

Your AI Performance Engineer. PerfPilot provides continuous, evidence-first performance review for AI inference workloads on Arm.

## What is implemented

- A polished Next.js dashboard with regression reporting, root-cause analysis, an optimization leaderboard, and PR-ready review output.
- A local FastAPI service that runs a reproducible CPU benchmark and exposes the evidence through documented endpoints.
- A GitHub Actions workflow targeting an Arm runner that saves raw benchmark evidence as a workflow artifact.
- Provenance is explicit throughout the product: values are **Measured** only when generated by a runner; modeled values are **Estimated**.

The dashboard content is a representative report shell. The repository-specific figures shown in its demo report are not offered as measurements of a user workload. The FastAPI endpoint is the source of actual locally measured evidence.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

In another terminal, start the benchmark service:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r backend/requirements.txt
uvicorn backend.main:app --reload
```

Then use the interactive API documentation at http://localhost:8000/docs or run:

```bash
curl -X POST http://localhost:8000/v1/benchmarks/run \
  -H 'content-type: application/json' \
  -d '{"iterations": 100, "workload_size": 4000}'
```

## Evidence model

`backend/main.py` intentionally does not infer performance changes from a repository name. The local `/v1/benchmarks/run` response includes method, configuration, individual samples, and provenance for every metric. A production integration should collect the same artifact for both base and PR revisions before calculating regressions.

## Next integration seam

Replace the deterministic workload in `backend/main.py` with adapters for the model and runtime under test (PyTorch Profiler, ONNX Runtime, or llama.cpp). Preserve the response schema and attach the exact model hash, runtime version, target CPU, and benchmark configuration to every artifact.
